# AI Tool Log

This file records meaningful use of Claude Code, Cursor, Antigravity, or Codex during development. Keep the actual conversation history required by the assignment separately.

## Five useful prompts

1. **Architecture review**  
   “Review this design against the capstone requirements. Identify missing requirements, unnecessary complexity, API boundaries, and the smallest reliable implementation plan. Do not invent evaluation results.”

2. **Knowledge ingestion**  
   “Implement a resumable sitemap crawler with bounded concurrency, retries with backoff, content hashing, and tests for interruption, duplicate URLs, updates, and deletions. Explain each design decision.”

3. **API contract**  
   “Define a typed request/response contract for question answering with answer text, citations, confidence, and an abstention state. Add validation and tests for malformed responses.”

4. **Inbox safety**  
   “Review the email agent for prompt injection, unsupported claims, sensitive requests, invalid structured output, and unsafe autonomous sending. Propose tests before changing the implementation.”

5. **Evaluation harness**  
   “Build a repeatable evaluation runner that records case ID, model and prompt version, quality ratings, token usage, cost, latency, retries, and errors. Keep measured values separate from assumptions.”

## A time an AI answer was rejected

**Record this during development:** Include one real suggestion from the coding assistant that was rejected, the reason it was unsafe or unsuitable, and the alternative chosen. Do not invent a development incident.
